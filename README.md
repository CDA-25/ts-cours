# ts-cours
cours typescript


1er commande : npm create vite@latest (créer un projet)
2eme commande : npm install (pour installer les dépendances)
3eme commaande : code . (pour ouvrir le projet dans le code)
4eme commande : docker compose up -d (pour lancer le docker)
5eme commande : docker exec -it nom_du_docker sh (pour entrer dans le docker)

On peux au debut telecharger (copier coller) les fichier 
    - compose.yaml
    - Dockerfile
    - entrypoint.sh
    - vite.config.ts
ps: pensez à modifier le port pour eviter les conflits
